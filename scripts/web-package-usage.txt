世界工坊 Windows 网页端 v{{version}}

启动
1. 将压缩包完整解压到一个文件夹。
2. 双击“启动世界工坊.bat”。命令窗口会自动隐藏，浏览器会打开世界工坊。
3. 关闭所有打开的世界工坊网页后，本机服务会自动停止；如果浏览器意外崩溃，服务也会在一段时间后自动退出。

更新说明
- 本次完整更新说明见“docs/更新说明-v1.3.0-20261031.md”，或应用资源“web/docs”内同名文件。

模板
- 安装包内附带“模板”文件夹，共 18 份 ZIP 模板。在应用内点“导入”，直接选择 ZIP，无需解压。
- 导出可选整个世界、分类、类型或单个设定。完整世界导入会替换当前档案，局部包则合并；重复项可跳过、更新或另存副本。
- 单项 ZIP 只放一份设定 JSON 和图片；批量导出按类型分文件夹。旧版 JSON 仍可导入。

档案与网络
- 档案保存在浏览器的本地数据中；不同浏览器分别保存。换电脑前请在应用中导出备份。
- 使用 AI 助手需要网络，并需要在应用内配置 AI 服务。
- 此启动包只允许本机访问，不是可直接从互联网打开的网站。若要给朋友通过网址访问，需要部署到 HTTPS 网站。
- 启动服务使用 Windows 自带 PowerShell，无需另外安装 Python 或 Node.js。
