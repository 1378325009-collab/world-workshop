世界工坊 Windows 电脑版 v1.3.0

启动
1. 解压收到的 ZIP 压缩包。
2. 双击“世界工坊.exe”。不需要另外安装 Python、Node.js 或浏览器。

档案与网络
- 世界档案保存在这台电脑当前 Windows 用户的本地应用数据中。
- 换电脑前，在应用中使用“导出备份”；在另一台电脑上用“导入”恢复。
- 使用 AI 助手需要网络，并需要在应用内配置 AI 服务。

模板
- ZIP 内附带“模板”文件夹，ZIP 模板也已内置在应用资源中。
- 可在应用内直接导入 ZIP 模板，无需解压；导出可选整世界、分类、类型或单个设定，局部包导入时合并。旧版 JSON 仍可导入。

Windows 提示
当前应用没有代码签名证书。首次运行时，Windows 可能显示“无法识别的应用”提示；确认压缩包来自可信来源后，可在 SmartScreen 页面选择“更多信息”再点“仍要运行”。
