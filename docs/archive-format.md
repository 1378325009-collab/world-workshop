# 世界工坊 ZIP 档案

ZIP 可直接解压阅读，也可在应用内直接导入，无需手动解压。单个设定项使用精简结构；整个世界、分类和类型使用按目录组织的结构，两者均支持电脑和手机。

## 单个设定项

例如单独导出人物“洛米拉”时，ZIP 内只有以下文件，没有外层文件夹、单独的清单或分类文件：

```text
洛米拉.json
图片/图片-0001.png
图片/图片-0002.webp
```

没有图片时只生成一份设定 JSON。JSON 顶层保存此项的名称、ID、类型、正文、自定义字段等内容；`__worldWorkshop` 保存格式标记 `world-workshop-entry`、格式版本 `1`、导出时间、来源世界 ID/名称/创建时间、所属分类和类型的完整字段定义、包外上级位置引用及图片清单。必要定义内嵌在这一份 JSON 中，因此导入到其他世界仍可恢复字段，不需要额外的定义文件。

图片从 JSON 中分离，以 `{"__worldWorkshopAsset":"图片/图片-0001.png"}` 引用，图片清单记录相对路径、类型和大小。相同图片只保存一份，有图片的字段定义也使用同样的引用方式。导入时选择完整 ZIP，将此项合并到当前世界。手动编辑时保留 ID、字段键和 `__worldWorkshop`；修改图片路径时同步调整引用和图片清单。

## 整个世界、分类和类型

格式标记：`world-workshop-archive`，新导出的格式版本为 `2`，支持导入旧版 `1` 和既有的单项档案。

```text
世界名称-世界档案/
  manifest.json
  档案信息.json
  分类/分类名称__0001/分类定义.json
  设定/类型名称__0001/
    类型定义.json
    设定名称__0001.json
  关系类型.json
  关系.json
  时间线.json
  地图/地图名称__0001/地图信息.json
  关系图谱/图谱名称__0001.json
  剧本/剧本名称__0001.json
  图片/图片-0001.webp
  扩展信息.json
  阅读说明.txt
```

上图展示有对应内容时的完整结构。关系类型、关系、时间线为空时不生成对应 JSON，扩展信息为空时也省略；地图、图谱、剧本与图片目录仅在有内容时出现。分类与类型包只携带选中范围及所需定义，不包含其他设定项。单项导出使用上一节的精简结构。

版本 2 中，清单可省略 `relationTypes`、`relations`、`events` 和 `extras` 路径；读取时分别还原为空数组和空对象。有路径但文件缺失仍视为档案损坏。版本 1 的旧包仍按原清单读取，现有模板无需重新转换。

每条 JSON 是该记录的唯一数据源；没有额外整世界快照。文件夹及文件名保留可读名称，序号区分重名，逻辑关联以 ID 为准。分类定义保存通用字段，类型定义保存专属字段与排序，设定文件保存内容。图片从内嵌数据拆成独立文件，以 `{"__worldWorkshopAsset":"图片/图片-0001.webp"}` 引用；相同图片只存一份。外部图片地址保留地址，离线使用需要原地址可访问。

`manifest.json` 保存格式版本、原数据版本、导出时间、范围、记录 ID 与相对路径、图片类型与大小、包外上级位置引用。手动编辑内容时保留 ID 与字段键；增删或重命名文件时同步修改清单。导入限制为 512 MiB、50,000 个文件。

## 范围与导入

选择“单个设定项”导出时，可先按设定类型筛选，再按名称、别名或标签搜索。类型选择器按一级分类组织并显示条目数量；选“全部类型”时，结果列表仍按类型分组。从资料卡直接导出会定位到对应类型和条目。未选中条目或没有匹配结果时，导出按钮不可用。分类与类型导出也支持名称搜索。

| 导出范围 | 包含 | 导入行为 |
| --- | --- | --- |
| 整个世界 | 所有设定、定义、关系、地图、图谱、时间线、剧本和图片 | 显示确认窗口，替换活动档案 |
| 一级分类 | 分类下所有类型及设定、所需字段定义、包内关系与图片 | 合并到当前世界 |
| 设定类型 | 此类型全部设定、所需分类与字段定义、包内关系与图片 | 合并到当前世界 |
| 单个设定项 | 一份设定 JSON（内嵌分类、类型及字段定义）和此项图片 | 合并到当前世界 |

局部包仅保留两端均在包内的关系。关系的类型限制如果引用其他设定类型，会携带必要的类型定义，不会附带这些类型的设定项。局部包不包含地图、图谱、事件和剧本。

导入局部包时按记录 ID 判断重复，不按显示名称判断。默认跳过重复条目及涉及它们的导入关系；也可选择更新记录或另存副本。副本使用新 ID，包内关系和上级位置随之重连。包外上级位置仅在来源世界 ID 和创建时间均相同、且目标仍存在时恢复，否则作为顶层位置导入并提示补充。

完全相同的分类和类型定义复用，发生冲突则另存新定义，重新映射字段键与类型引用，不覆盖现有分类配置。地理类型另存后仍保留地理层级能力。关系类型的范围、标签和 ID 也会处理冲突；更新后不适用的节点关系会阻止提交。导入先读取、预览，确认后才保存；存储失败时保留原活动档案。

旧版完整世界 JSON 仍可导入。18 份本地模板已使用相同打包器转换为完整世界 ZIP，原 JSON 已保存在项目外的本机备份目录。转换工具：`scripts/convert-templates.mjs`；只有显式传入 `--remove-originals` 才在保存并回读一致后移除原 JSON。

ZIP 仅包含世界档案内容，不包含 AI 接口密钥、聊天记录或设备设置。电脑与手机使用相同格式，跨设备通过导出和导入迁移。
