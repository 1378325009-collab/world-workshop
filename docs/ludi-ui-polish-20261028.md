# Ludi 界面细节应用 · 2026-10-28

本次将项目技能 `.agents/skills/ludi-ai-ui/SKILL.md` 用于世界工坊现有网页，保持当前主题与布局。

## 聊天阅读位置

- 接近底部（32px 内）时跟随新内容；上翻后暂停，并显示“跳至最新”。
- 主动发送聊天或绘图请求时恢复跟随；后台回复追加不会强制拉回底部。
- 重绘时以当前消息及其可见偏移保留位置；布局观察器处理图片读取、消息高度与面板尺寸变化。
- 切换世界档案重置阅读状态。后台更新只恢复原来聚焦的输入框与选区；打开面板时聚焦输入框。

## 分栏调整

- AI 助手和设定资料卡均可即时拖宽，正常松手后保存。
- Esc、指针取消、丢失指针捕获或窗口失焦时撤销本次拖动。
- 双击分隔条或聚焦后按 Home，恢复默认宽度：助手 430px，资料卡 420px，并继续遵循视口边界。
- 方向键微调和 Shift 加大步长继续可用。

## 显示细节

- 附件和生成图片的长文件名只省略主体，保留扩展名与完整 title，保存仍使用原始名称。
- 统计、缩放、对话轮数、消息时间、附件大小与进度使用等宽数字。
- 输入区按间距调整内外圆角；内部辅助按钮、附件和关系类型卡片以背景区分层次。
- 聊天自动定位即时完成；低高度窗口允许输入区内部滚动；分隔条装饰响应减少动态效果设置。
- 保留已有的中文选字回车保护，以及非流式接口的等待与完整回复呈现。
