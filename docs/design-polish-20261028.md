## 设计调整

| Before | After | Why |
| --- | --- | --- |
| 概览数字和内容依靠连续分隔线排列 | 四张独立统计卡片，世界基底、最近更新与右栏使用统一纸面卡片 | 更容易区分总览数字与创作资料 |
| 统计数字仅用于阅读 | 点击统计卡片可前往设定库、关系图谱、时间线和设定检查 | 从概览直接进入对应工作 |
| 分类筛选、状态和排序挤在同一行 | 分类使用独立横向滚动行，状态和排序放在下一行 | 完整保留分类入口，减少控件互相挤压 |
| 图谱模式依靠不同按钮背景表达 | 三种模式放在同一分段控件中，保留选中状态和操作提示 | 更容易判断当前操作方式 |
| AI 输入框与附件、绘图、发送共用一行 | 输入框单独占一行，操作按钮集中在下方 | 较窄面板也能留下足够输入空间 |
| 控件尺寸、圆角、文字层级各自设置 | 使用统一尺寸、层次和短暂的按压反馈 | 提升操作一致性 |
| 手机概览侧栏内容较长 | 覆盖统计以两列展示，卡片和触控尺寸适配窄屏 | 减少纵向重复，并保留清楚的阅读顺序 |
| 弹窗进场使用固定动画 | 高频操作直接呈现；按钮使用 140ms 按压反馈，减少动态效果偏好下取消位移 | 避免等待装饰动画，及时确认操作 |
