# 世界工坊 v1.3.0 更新说明

发布日期：2026-10-31。Android 构建号：8。

本说明以 GitHub 仓库上次更新的 `main` 提交 [`b186cda`](https://github.com/1378325009-collab/world-workshop/commit/b186cda7ac5673efa1ec9c585879b91504eb08b2)（2026-10-20）为对比基准，汇总其后积累的功能和修复。

## 本次分别提供的安装包

| 文件 | 用途 |
| --- | --- |
| `世界工坊-1.3.0-网页端-Windows-x64.zip` | 完整解压后双击“启动世界工坊.bat”，在浏览器中使用。附带模板、说明和更新文档；其中 `web/` 也可部署到 HTTPS 静态站点。 |
| `世界工坊-1.3.0-Android.apk` | Android 独立 App，网页资源内置，可离线启动。沿用既有包名和调试签名，可覆盖安装。 |

GitHub 下载文件使用稳定的英文名称：网页版为 `world-workshop-1.3.0-web-windows-x64.zip`，Android 为 `world-workshop-1.3.0-android.apk`；本地打包产物保留上表的中文名称。发布页中的 SHA-256 校验文件对应英文下载名称。

两个包从同一份网页源码构建。本次不重新发布旧的 Windows Electron 桌面包，也不提供 iOS 安装包。下载入口位于 [GitHub v1.3.0 发布页](https://github.com/1378325009-collab/world-workshop/releases/tag/v1.3.0)，附 SHA-256 校验文件。

## 与上次版本相比

### 设定库和图标

- 一级分类和次级类型默认具有图标字段，可上传图片并调整圆形裁切范围。条目优先显示次级类型图标，没有时回退到分类图标。
- 图标、通用字段和专属字段支持顺序调整，资料卡按设定顺序展示。
- 搜索与状态、排序放在同一行，类型筛选保持独立；移除右上角重复的设定数量。
- 资料卡与 AI 助手面板宽度可拖动调整，并支持键盘微调、Esc 撤销、双击或 Home 复位。

### 关系图谱

- 增加浏览、选区、关联三种模式。选区模式可框选并整体拖动节点；关联模式依次点击两个节点建立关系，再次点击起点可取消。
- 节点使用圆形图标和下方文字，长名称最多两行；缩小时简化节点显示。
- 右侧改为按设定类型组织的“节点图层”。箭头负责展开，眼睛负责显示，类型名和节点名负责选中；侧栏与画布高亮联动。
- 可按类型批量显示、隐藏或选中节点，支持搜索及组合键追加选择。
- 关系类型可自定义，起点和终点各自设置允许的设定类型。预置关系可继续编辑，管理界面可按起点、终点筛选。
- 关系改名同步到连线；修改关系限制或条目类型时检查适用范围。
- 鼠标中键拖动画布，手机支持触屏平移、双指缩放和点击关联；保留从节点开始双指缩放时的手势处理。
- 调整图谱主区与侧栏的高度对齐；没有活动图谱时清理残留的关联起点。

### 地图图层

- 全部已有设定按类型收录到地图图层，新建设定也会加入；默认处于“未标注”，需要手动放置到地图上。
- 点击未标注设定后在地图上放置标记，点击已有标记可选中并定位。
- 支持类型组和单个标记的显示控制、搜索、展开与折叠。移除地图标记后，设定仍保留在图层中。
- 各张地图分别保存位置与可见状态，兼容原有标记；手机图层排在地图下方。

### AI 助手与绘图

- 明确的绘图请求可直接调用图片接口；支持工具调用的聊天模型也可通过 `generate_image` 发起绘图。
- 图片接口可单独配置模型、密钥与分组；提供模型查询和实际生图检查。
- “不要文字”“换成蓝色”等后续修改沿用此前图片主题和参考图；本轮上传的图片优先作为参考，重新检索对应世界设定。
- 验证返回数据确实为可解码图片后再显示成功。网络错误区分参考图读取、请求提交、响应读取与图片下载阶段，失败时保留附件。
- 上翻聊天后暂停自动跟随，点击“跳至最新”或主动发送可返回底部；回复重绘、图片加载和调整面板宽度时尽量保留阅读位置。
- 长附件名保留扩展名，统计与时间使用等宽数字；整理输入区、附件卡片和操作按钮的层次。

图片生成仍取决于所配置服务的网络和模型能力；参考图修改需要服务支持 `/images/edits`。本次打包没有调用外部 AI 或付费图片接口。

### ZIP 导入、导出和模板

- 导出范围从整个世界扩展到一级分类、设定类型、单个设定项，统一生成 ZIP。
- 单项导出可先选类型，再按名称、别名或标签搜索；从资料卡导出时自动定位到当前设定。
- 单个设定 ZIP 内只放一份以设定名称命名的 JSON 和图片，字段定义内嵌，方便分享人物或其他条目。
- 批量包按类型分文件夹，每项设定独立保存。图片拆分为独立文件，相同图片去重；空关系、时间线及扩展信息不生成占位文件。
- 局部包导入时先预览，再合并到当前世界；重复 ID 可选择跳过、更新或另存副本。
- 字段定义发生冲突时保留双方定义并映射字段键，副本的包内关系与上级位置随之重连。
- 继续支持旧版完整世界 JSON、既有 ZIP 档案和旧单项 ZIP。
- 本地 18 份模板统一提供 ZIP 格式。仓库保留这些 ZIP，替代原 JSON 模板；修正忽略规则，避免模板被打包或提交时遗漏。
- 导出窗口的筛选、摘要和说明占完整行宽，手机上按上下顺序排列。

具体文件结构与导入规则见 [ZIP 档案格式](archive-format.md)。

### 手机、离线和分开打包

- 增加手机窄屏布局、触控尺寸及 PWA 安装入口，应用界面支持离线缓存。
- 增加 Android 原生封装、系统返回键与文件分享保存，APK 内置完整网页资源和模板。
- 增加 Windows 本机网页启动包，无需另装 Python、Node.js 或 Electron，关闭全部应用网页后服务自动停止。
- 本次统一版本号为 v1.3.0，更新网页缓存标识，Android 构建号递增至 8。
- 提供 `npm run web:package` 与 `npm run android:package`，分别生成网页 ZIP 和带版本号的 APK。

## 更新和数据说明

Android 直接覆盖安装，无需卸载。网页版请完整解压新包，再使用原来的浏览器和访问地址；刷新页面即可获取新资源。应用数据按设备、浏览器和站点地址独立保存，更换设备、浏览器或地址前请先导出备份。

世界 ZIP、模板和安装包不包含本机 AI 密钥、聊天记录或个人档案。完整世界或模板导入会替换活动档案；分类、类型和单项包则合并到当前世界。更新应用不会使不同设备自动同步数据。

## 发布范围

本次发布完成网页和 Android 打包，并核对版本、签名、资源一致性及模板数量。更新文档随网页包和 APK 内置文档一起发布。没有对全部业务功能逐项回归，也没有在实体手机上验收。

多智能体管理、云端同步和深层语义一致性审查仍属于后续目标，本次未提供。
