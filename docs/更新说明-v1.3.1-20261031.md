# 世界工坊 v1.3.1 更新说明

发布日期：2026-10-31。Android 构建号：9。

## 公开模板作为默认展示

全新设备或没有本地档案时，默认打开现有《蛊真人》展示模板，包含 74 条设定、85 条关系、28 条时间线事件和 7 份剧本。展示内容直接来自仓库中的公开模板 ZIP。

移除原内置私有世界介绍、私有条目、品牌副标题和地图占位示例。助手头像改用世界工坊应用图标，私有角色头像不再随新包分发。档案格式说明使用通用的“示例人物”名称。

## 固定后续发布规则

- `release-example.json` 记录当前选用的公开模板。
- `scripts/prepare-release-example.mjs` 从该模板生成 `default-world.js`，网页、Android 和桌面打包均自动执行。
- 后续发布必须使用公开模板，不得把个人世界、角色素材、聊天记录、图片或接口配置作为演示内容；要求已写入项目 `AGENTS.md`。
- Android 打包先清理生成的网页目录，避免旧素材残留在新安装包中。

## 升级与下载

已有设备继续读取原来的本地档案，不会强制替换为演示模板；要查看演示，可在备份现有资料后手动导入《蛊真人》模板。既有存储标识、应用包名和签名继续保留，以支持覆盖更新。

本次单独提供网页 ZIP 和 Android APK，下载文件名分别为 `world-workshop-1.3.1-web-windows-x64.zip` 和 `world-workshop-1.3.1-android.apk`，本地打包文件保留中文名称。

旧版 v1.3.0 下载撤回，新版见 [v1.3.1 发布页](https://github.com/1378325009-collab/world-workshop/releases/tag/v1.3.1)。本次没有改写 Git 历史，旧提交中的默认内容仍可从历史记录中找到。
