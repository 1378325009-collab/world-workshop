# 世界工坊模板

## 使用

1. 在世界工坊当前档案中先选择“导出备份”，保存已有内容。
2. 选择“导入”，再选上表中的 ZIP 模板（直接选择 ZIP）。
3. 导入确认后，模板会替换当前浏览器中的活动档案。

所有模板都可以继续改写。文本、图片和多边形数值可作为自定义字段；每个一级分类和次级类型都会默认提供不可删除的专属图标字段，上传图片后可作为条目和关系节点的图标，次级类型图标优先于一级分类通用图标。进入“管理设定类型”还可以调整其它字段和资料卡顺序。

可通过“导出备份”选择整个世界、一级分类、设定类型或单个设定项。局部包导入时合并到当前世界，可跳过、更新或另存重复项。旧版 JSON 档案仍支持导入。详细结构见 [档案格式说明](../docs/archive-format.md)。
