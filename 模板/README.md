# 世界工坊模板

这些 JSON 文件都是可直接导入的世界档案模板。每份模板都包含题材化的概览、设定类型分组、次级类型、字段顺序，以及一条草稿世界基底；其它条目保持空白，便于按自己的故事扩写。

## 使用

1. 在世界工坊当前档案中先选择“导出备份”，保存已有内容。
2. 选择“导入”，再选上表中的 JSON 模板。
3. 导入确认后，模板会替换当前浏览器中的活动档案。

所有模板都可以继续改写。字段类型包括文本、图片、专属图标和多边形数值；进入“管理设定类型”还可以调整字段和资料卡顺序。
